# SQL 方言选择

使用此参考将可移植 SQL 规则与提供者特定实现规则分开。

## When To Use

- 任务变更了 schema、迁移 SQL、手写 SQL、ORM 原生查询、分页、日期/时间表达式、JSON 表达式、upsert 行为或提供者特定映射。
- 已接受的技术基线命名了其语法、类型亲和性、索引行为或事务行为影响任务的数据库提供者。
- 不要为不拥有持久化行为的 API、控制器、前端或服务任务加载方言指导。

## Source Facts

- 将已接受的技术基线、仓库迁移文件、驱动程序、ORM 和运行时配置视为提供者真相来源。
- 保持提供者标识与任务主题分开。选择 PostgreSQL 不会自动使任务成为查询、迁移、性能或事务任务。
- 不要从任务标题或业务正文推断提供者。MCP 选择使用结构化技术栈信号和任务所有权。
- 如果提供者版本、扩展、迁移工具或 ORM 映射未知，使用可移植子集并记录确切的兼容性缺口。

## Implementation Focus

- 使用目标提供者的标识、类型、时间戳、decimal、JSON、enum、引用、参数和排序规则语义。
- 保持 schema 或迁移 SQL、ORM 映射、序列化 API 字段和持久化测试对齐。
- 为分页保留确定性排序并包含稳定决胜键。
- 将 upsert 冲突目标、受影响行行为和重试/幂等语义视为契约的一部分。
- 不要因为看起来等效就从另一个提供者复制语法。

## Provider Decision Matrix

在使用提供者特性之前，记录跨越应用边界的行为。覆盖按任务主题选择；它不授权该提供者支持的每个特性。

| 决策面 | 实现前需要回答的问题 |
|---|---|
| 标识和键 | 键由 identity、sequence、UUID 还是应用生成？生成值如何回读？ |
| 布尔和空值 | 布尔、空字符串和 `NULL` 是否由驱动程序和 API 以相同方式表示和比较？ |
| 时间和数字 | 类型是否保留时区、精度、标度、舍入和序列化语义？ |
| JSON 和特殊类型 | 提供者类型是否被领域需要、被拥有的查询索引并被已接受的版本/驱动程序支持？ |
| 分页和排序 | 语法是否保留稳定排序、决胜、总数和请求的页面边界？ |
| Upsert 和受影响行 | 冲突键、无操作结果、生成值行为和重试/幂等结果是什么？ |
| 大小写和排序规则 | 提供者配置施加了哪些比较、唯一性、排序和索引语义？ |
| 事务和锁 | 此操作需要并验证了哪种隔离、锁、死锁或序列化行为？ |

如果决策无法从已接受的基线、仓库事实或提供者验证中回答，保持实现可移植并记录未解决的提供者行为而非编造默认值。

## Provider Overlays

MCP 仅在任务拥有匹配主题时才将选中的 SQL 参考组映射到提供者覆盖：

| 提供者 | 覆盖参考 |
|---|---|
| MySQL | `mysql.schema`、`mysql.queries`、`mysql.transactions` |
| PostgreSQL | `postgresql.schema`、`postgresql.queries`、`postgresql.transactions` |
| SQL Server | `sqlserver.schema`、`sqlserver.queries`、`sqlserver.transactions` |
| Oracle | `oracle.schema`、`oracle.queries`、`oracle.transactions` |

MariaDB 仍然是单独的提供者信号。它不得在没有显式兼容性决策的情况下静默加载 MySQL 覆盖。SQLite 和其他提供者使用可移植规则直到专用覆盖可用；结果必须记录未验证的提供者特定行为。

## Verification Focus

- 针对配置的目标/测试提供者运行提供者敏感的迁移、映射或查询。
- 当映射或迁移变更时验证 ORM 启动/schema 验证。
- 对任务拥有的类型、null、排序、JSON、upsert、锁或分页行为使用代表性数据。
- 如果提供者不可用，记录确切未验证的行为并保持实现保守。

## Evidence Focus

说明选中的提供者和已证明的决策：类型映射、标识、时间语义、分页、JSON、upsert、索引行为、事务行为或目标提供者证明。

## Risks To Avoid

- 为每个持久化任务加载每个提供者覆盖。
- 将提供者名视为添加提供者专有特性的许可。
- 从不同数据库（如 SQLite 或 H2）声称方言兼容性。
- 用通用成功单元测试隐藏版本、扩展、ORM 或迁移不兼容性。
- 将没有选中覆盖的已识别提供者视为完全提供者验证。
